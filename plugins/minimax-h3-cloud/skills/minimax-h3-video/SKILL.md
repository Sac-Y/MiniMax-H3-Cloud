# MiniMax H3 云端视频

通过插件根目录的 `scripts/h3-cloud` 调用已验证的本地编排器。相对本文件的位置是 `../../scripts/h3-cloud`；执行前把它解析为绝对路径。

## 运行原则

- 正式默认使用优云 ComfyUI 纯净版 Runtime Profile。社区镜像只作为回归证据；不要把镜像 ID、ComfyUI 地址或工作流节点写进 Skill，运行时读取 Deployment Binding 和 Runtime Spec。
- 不设置独立欢迎页或单选项平台页。只有用户主动询问插件能力时才简短介绍五种模式；首次配置直接说明当前使用“优云智算”，并把平台注册、API Key 配置和凭证录入放在同一步。
- 整个首次流程采用单步推进。每个回合只呈现当前必须完成的一步和一项明确操作；当前步骤未完成时，不预告、不展开后续步骤。顺序固定为：API Key 配置 → 凭证验证与 GPU 选择 → 提示词/素材和参数 → 单次付费确认 → 生成与结果。系统内部可连续执行不需要用户决定的检查，但不得一次性把完整流程倾倒给用户。
- 首次使用必须渐进披露。如果本机凭证尚未配置或尚未验证，当前回合只能完成 API Key 引导并在请用户回复“已完成”后结束。此时不得介绍 GPU、视频模式、提示词格式、画幅、时长、清晰度、费用或生成步骤，也不得要求用户提供提示词。只有下一回合验证凭证成功后，才能进入 GPU 选择。
- 优云凭证由官方 `compshare-cli` 的本机 profile 管理。不要读取、打印、复制或要求用户发送 API Key。
- 本插件不分发模型权重。MiniMax H3 的社区许可证目前排除欧盟、英国、韩国和美国等地区；不要根据 IP、时区或语言推断用户所在地。如果用户明确位于排除地区或对授权不确定，不得启动付费资源，应请其先取得 MiniMax 的单独授权并阅读完整许可证：<https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/LICENSE>。
- 实例尚未建立时，先运行只读 `h3-provision plan`；只有用户确认 API 返回的选定区域、库存和小时价格后，才运行 `h3-provision create --yes`。
- 用户明确要求生成视频，授权一次对应的付费生成任务；开始前只确认视频模式、画幅、时长、清晰度和预计本次生成费用。预计费用必须基于最新只读计划中的价格与同类任务耗时估算，并明确是估算值。未明确要求生成时，只运行只读的 `status` 或 `plan`。
- 用户说明图片必须成为视频开头画面时，使用首帧关键帧模式，把绝对路径传给 `--first-frame-image`。
- 用户说明图片必须成为视频结束画面时，使用尾帧关键帧模式，把绝对路径传给 `--last-frame-image`。
- 用户同时指定开始和结束画面时，同时传入 `--first-frame-image` 与 `--last-frame-image`。三种关键帧模式复用同一个 FL2VA Turbo 8-step 工作流，不新增模型下载。
- 用户说明图片只用于保持人物、主体或视觉风格，并不要求它成为首帧或尾帧时，使用独立参考图模式；每张图片各传一次 `--reference-image`，按参数顺序支持 1–9 张。用户只说“参考图”且意图不清时，先确认它是关键帧还是角色/主体/风格参考；参考图模式不能与任何关键帧参数同时使用。
- 首帧和首尾帧已经通过优云实机语义验证；单尾帧仍是候选能力，正式发布前需要一次低成本实机验收。
- 参考图支持 1–9 张，走官方 Ref2VA 原生 20-step；单图和多图均已完成优云实机语义验证。
- 默认让编排器设置兜底关机，并在成功、失败或中断后立即关机。除非用户明确要求保留实例，否则不要传 `--keep-running`。
- 新用户必须在三个并列配置中主动选择，不预选、不使用“推荐方案”标签，也不在配置之间静默回退。每项只展示硬件、价格、一句事实依据和一句必要限制。用户也可以要求查看平台当前全部单卡规格。
- 当前三个配置是 `5090-96gb`、`5090-64gb`、`4090-64gb`。前两项继续作为正式测试基线；`4090-64gb` 为未验证低价实验项，付费前必须明确说明没有 H3 速度与稳定性保证。不得现场下载或复制 42.5GB 模型。
- `generate` 会在提交前自动执行幂等 Runtime Prepare：校验当前六个模型/LoRA 文件的大小与 SHA-256，仅创建安全软链接；后续快速复查。不要要求用户登录 SSH、手工操作 ComfyUI 或重新下载平台已有模型。
- 一旦 ComfyUI 返回 `prompt_id`，manifest 会立即持久化。之后出现 SSH/HTTP 断线时，编排器只重建通道并恢复原 `prompt_id` 的查询与下载，绝不自动提交第二个付费任务。

## 视频参数

用户准备提示词时，先用一句话提醒他尽量同时写明：

- 画面内容和运动；
- 画幅，例如 `16:9 横屏`、`9:16 竖屏` 或 `1:1`；
- 时长，当前支持 2–15 秒；
- 清晰度，当前支持 0.2–1.0MP。

可直接给出示例：`一只橘猫坐在海边看日落，微风吹动毛发，电影感；16:9 横屏；10 秒；0.98MP（约 768P）`。

如果用户提供首帧图片，提示词重点描述“从这张画面开始之后发生的运动、镜头和声音”，不需要重复描述图片里已经确定的静态构图。支持 PNG、JPG、JPEG 和 WebP；本地文件会在 GPU 启动前校验，并在任务开始后上传到 ComfyUI 的独立输入目录。该模式复用相同 H3 模型和 Turbo 工作流，不额外下载模型。

如果用户提供尾帧图片，提示词重点描述“画面如何自然运动到这张结束画面”。如果同时提供首帧和尾帧，提示词重点描述两张画面之间的动作、镜头和场景过渡。首尾图片都在 GPU 启动前校验，并分别上传到任务独立目录。

如果用户提供角色/主体/风格参考图，提示词描述希望保留的特征以及新场景中的动作、镜头和声音，不要求从原图构图开始。编排器会按参数顺序自动添加与图片数量一致的 `<Picture 1>`…`<Picture N>` 标签；不要手工写标签，也不要把参考图改成首帧输入。该模式使用独立 Ref2VA 主模型，但从平台缓存零复制映射，不要求用户现场下载。

如果用户已经明确写出画幅、时长和清晰度，直接解析为结构化参数并生成，不再让用户选择预设。只缺少其中一项时，仅询问缺少项；“高清”“尽量清晰”等不能唯一确定数值的描述仍需让用户选择。

MP 是总像素量，P 是画面高度，两者会随画幅变化。以下只用于 `16:9` 横屏的直观参考：

| 清晰度 | 当前工作流约输出 | 常用理解 |
|---|---:|---:|
| 0.4MP | 864×480 | 约 480P |
| 0.6MP | 1056×608 | 约 600P |
| 0.8MP | 1216×672 | 约 670P |
| 0.9MP | 1280×736 | 接近 720P |
| 0.98MP | 1344×768 | 约 768P |
| 1.0MP | 1376×768 | 约 768P，横向略宽 |

用户明确写 `480P`、`720P` 或 `768P` 时，可以结合画幅按上表转换；转换前用一句话告知对应 MP。旧的 `preview`、`balanced`、`short_hq` 只保留为内部兼容快捷方式，不作为用户必选步骤。64GB Runtime 不运行 15 秒 0.9MP 或更高配置。

## 操作

1. 首次配置时直接说明当前使用优云智算，并只提供两个可点击入口：[注册或登录](https://passport.compshare.cn/register?referral_code=2N6NKqFVowEIxce0PT4kK)、[创建或管理 API Key](https://console.compshare.cn/uaccount/api_manage)。同时用一句话提示 MiniMax H3 受[社区许可证](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/LICENSE)及地域限制约束；不要单独显示欢迎页、平台选择页或“未来将支持更多平台”文案。
2. 如果本机尚无隔离凭证配置，让用户自行在终端运行 `compshare config set --name <隔离名称> --no-activate`，通过官方隐藏输入录入 API Key。插件不得读取或回显密钥。提醒用户不要把 API Key 发到对话中，并请他完成后只回复“已完成”；随后立即结束当前回合。这个结束点是硬性边界，不得继续展示 GPU 配置页、生成模式、参数示例、费用说明或索要提示词。下一回合先验证凭证，成功时只简短报告“优云智算已连接”，再进入第 3 步。
3. 凭证成功后运行 `scripts/h3-onboard options --platform compshare --credential-profile <隔离名称>`。优先使用 `request_user_input` 向用户展示一个 GPU 单选题，三个返回项按原顺序作为三个选项；选项描述合并 `priceDisplay`、`reason` 和必要的 `caveat`，不预选。如果客户端自动提供“其他”，明确告诉用户可用它提出配置需求或查看更多；没有该工具时才退化为编号列表，并增加“更多配置”。同时附上[优云 GPU 配置页](https://console.compshare.cn/light-gpu/console/resources)。`priceSource=reference` 时必须说明是历史参考价，创建前仍会刷新。
4. 用户选择“其他/更多”或提出其他需求时，运行 `scripts/h3-onboard options --platform compshare --all --credential-profile <隔离名称>`，展示当前有库存的单卡规格和实时报价。列表只代表平台当前可售，不代表 MiniMax H3 已验证。
5. 用户明确选择后，运行 `scripts/h3-onboard init --platform compshare --resource-option <配置ID> --credential-profile <隔离名称>`。默认配置位于 `~/.config/minimax-h3-cloud/config.json`；如果该路径已经存在，先读取并确认是否复用，不得覆盖。该命令不接收 API Key，也不会保存已有实例 ID。
6. 对隔离配置运行 `scripts/h3-provision plan --config <隔离配置路径>`，内部检查所选规格的区域、镜像、缓存、库存和实时价格。不得切换到另一项配置；库存不足时回到第 3 步。生成前面向用户的确认只包含视频模式、画幅、时长、清晰度和预计本次费用，不展示镜像、缓存或内部证据状态。得到用户确认后再运行 `scripts/h3-provision create --yes --config <隔离配置路径>`。创建成功会自动保存新实例 ID。
7. 已有配置时先运行 `scripts/h3-cloud status --config <配置路径>`。不得在全新用户验收中使用开发者默认配置、已有 credential profile 或已有实例 ID。
8. 用户准备提示词时，提醒他写明画幅、时长和清晰度，并按“视频参数”一节解析。三项齐全时直接继续；缺项时只询问缺少项。将画面提示词写入一个临时 UTF-8 文本文件，再传给 `--prompt-file`；不要把画幅、时长和清晰度混入工作流的画面提示词，也不要修改基线工作流文件。
9. 执行 `scripts/h3-cloud generate --config <配置路径> --aspect-ratio <画幅> --duration-seconds <秒> --megapixels <MP> [--prompt-file <path>] [--first-frame-image <首帧绝对路径>] [--last-frame-image <尾帧绝对路径>] [--reference-image <参考图绝对路径>]...`。不提供图片时为文生视频；只传首帧、只传尾帧或同时传首尾帧分别进入对应关键帧模式；参考图模式可重复传入 1–9 个 `--reference-image`，并与两个关键帧参数互斥。不要提前单独启动实例；该命令会负责自动启停、Runtime Prepare、断线恢复和生成下载。只有兼容旧调用时才使用 `--preset`。
10. 命令结束后再次运行 `scripts/h3-cloud status --config <配置路径>`，必须确认状态为 `stopped`。
11. 使用 `ffprobe` 检查输出 MP4 的时长、分辨率、视频和音频流。
12. 最终答复保持简洁：先使用本地 MP4 绝对路径的媒体 Markdown 直接显示播放器：`![MiniMax H3 生成视频](<绝对路径>)`；播放器下方紧接 `[下载 MP4](<同一个绝对路径>)`。随后只用一行列出实际时长、分辨率和 GPU 已停止；其他技术字段按需展开，不要求额外质量确认。

路径含空格时必须用尖括号包裹 Markdown 目标。不要只返回代码块、纯文本路径或云端临时 URL；视频必须已经下载到本机后再呈现。

如果生成命令异常退出，先查看 manifest：已有 `prompt_id` 时只能恢复原任务，不能重新生成；没有 `prompt_id` 才表示尚未确认提交。随后查询实例状态，仍为 `running` 时执行 `scripts/h3-cloud stop --yes`，并报告原始错误、恢复结果和清理结果。不要在原因不明时自动重复付费生成。
